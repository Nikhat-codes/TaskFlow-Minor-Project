# TaskFlow — Task Management Web Application

**A simple, responsive task manager built with HTML5, CSS3 and JavaScript.**

TaskFlow brings everyday tasks into one place. Add a task, set its priority and due date, keep track of its status, and use search and filters to find what needs attention.

## Features

### Task Management
- Add tasks with a title, description, priority and due date.
- Edit task details when plans change.
- Delete tasks with a confirmation prompt.
- Mark tasks as completed or pending.

### Organize and Track
- Search tasks by title or description.
- Filter tasks by status and priority.
- Sort tasks by newest first, due date or priority.
- View dashboard counts for total, pending, completed and overdue tasks.
- Identify overdue pending tasks through a visual label and highlighted task card.

### Responsive Interface
- Dashboard cards and task sections adapt to desktop, tablet and mobile screen sizes.
- Clear form controls and task action buttons make the application straightforward to use.

### Data Persistence
- Tasks are saved in the browser's Local Storage.
- Saved tasks are restored when the page is refreshed in the same browser profile.

## Run Locally

TaskFlow is a front-end application. It does not require a backend server or database.

1. Clone or download the repository:

   ```bash
   git clone https://github.com/Nikhat-codes/TaskFlow-Minor-Project.git
   ```

2. Open the project folder:

   ```bash
   cd TaskFlow-Minor-Project
   ```

3. Open the `source_code` folder.
4. Open `index.html` in a modern web browser.
5. Add a task and try the search, filters, sorting and task actions.

## How Task Data Is Stored

TaskFlow stores the task list in the browser's Local Storage. This means saved tasks remain available after refreshing the page in the same browser profile. The data is not automatically synchronized between different browsers or devices. Clearing the browser's site data may remove the saved tasks.
