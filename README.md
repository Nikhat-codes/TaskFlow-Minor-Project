## About the Project

Keeping track of tasks can become difficult when deadlines, priorities, and completion status are spread across different places. TaskFlow provides a single interface to add and manage tasks, review progress, and identify overdue work.

The application runs in a web browser. It saves tasks in that browser's Local Storage, so the task list remains available after refreshing the page on the same device and browser.

## Features

- **Create tasks** with a title, description, priority, and due date
- **Edit tasks** when their details change
- **Delete tasks** with a confirmation prompt
- **Track progress** by marking tasks complete or pending
- **Search tasks** by title or description
- **Filter tasks** by completion status and priority
- **Sort tasks** by due date, priority, or creation time
- **View dashboard totals** for all, pending, completed, and overdue tasks
- **Spot overdue work** with a clear visual label and highlighted task card
- **Keep tasks after refresh** using browser Local Storage
- **Use the interface on smaller screens** with a responsive layout

## Technology

- **HTML5** — page structure and form
- **CSS3** — visual design and responsive layout
- **JavaScript** — task management, search, filters, sorting, and dashboard
- **Browser Local Storage** — saves tasks in the current browser

## Run the Project

1. Download or clone this repository.
2. Open the `source_code` folder.
3. Open `index.html` in a modern web browser.
4. Add a task using the form and try the search, filters, sorting, and task actions.

The current version is a front-end application and does not require a server or database installation.

## Data and Privacy

Tasks are saved in Local Storage in the browser used to open TaskFlow. They are not automatically shared across browsers or devices and are not stored in an online account. Clearing that browser's site data may remove saved tasks.
